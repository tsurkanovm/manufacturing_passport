## Про модуль

Модуль `manufacturing_passport` розширює стандартний модуль виробництва Odoo (`mrp`) повноцінним документообігом контролю якості та технічних паспортів.

Розроблено для підприємств, де готовий виріб повинен пройти офіційну перевірку ВТК (відділ технічного контролю) перед відвантаженням. Кожен виріб отримує пронумерований паспорт із зазначенням серійного номера, дати виготовлення, гарантійного терміну та переліку використаних комплектуючих з прив'язкою до партій/серіалів.

**Orієнтовані галузі:** оборонна промисловість, машинобудування, виробництво електроніки, приладобудування.

## Можливості

### Контроль якості (QC)
- Створення **актів перевірки (випробувань)** безпосередньо з виробничого замовлення одним кліком
- **Шаблони перевірок** — збережіть стандартний перелік параметрів для продукту та автоматично заповнюйте нові акти
- Підтримка двох типів параметрів: **кількісний** (числові норми min/max) та **якісний** (текстовий опис)
- Автоматичне визначення результату рядка перевірки при введенні фактичного значення
- Журнал чатера з відстеженням усіх змін статусу (mail.thread)
- Можливість прикріплення файлів та фото до акту

### Паспорт виробу
- Автоматичне формування паспорта на підставі **затвердженого акту перевірки**
- Автозаповнення переліку комплектуючих з фактичними партіями/серіалами зі списань виробничого замовлення
- Автоматичний розрахунок **дати закінчення гарантії** на основі дати виготовлення та терміну (місяці)
- Наскрізна нумерація документів через `ir.sequence`
- Друк паспорта та акту перевірки у форматі PDF (QWeb-звіти)

### Інтеграція з виробничим замовленням
- **Smart-кнопки** на формі виробничого замовлення: швидкий перехід до актів перевірки та паспортів
- Захист від дублювання: неможливо створити другий затверджений акт або виданий паспорт для одного замовлення
- Блокування видачі паспорта без затвердженого акту перевірки

## Архітектура

```
manufacturing_passport/
├── models/
│   ├── mrp_production.py       # розширення mrp.production (smart-кнопки, дії)
│   ├── qc_template.py          # mrp.qc.template / mrp.qc.template.line
│   ├── qc_inspection.py        # mrp.qc.inspection / mrp.qc.inspection.line
│   └── product_passport.py     # mrp.product.passport / mrp.passport.component.line
├── views/
│   ├── qc_template_views.xml
│   ├── qc_inspection_views.xml
│   ├── product_passport_views.xml
│   ├── mrp_production_views.xml
│   └── menu.xml
├── reports/
│   ├── inspection_report.xml   # QWeb-звіт: акт перевірки
│   └── passport_report.xml     # QWeb-звіт: паспорт виробу
├── security/
│   ├── security.xml            # групи: Інспектор ОТК / Керівник ОТК
│   └── ir.model.access.csv
└── data/
    └── sequence_data.xml       # нумерація QC-XXXX / PP-XXXX
```

### Моделі даних

| Модель                        | Тип        | Опис                                    |
|-------------------------------|------------|-----------------------------------------|
| `mrp.production`              | `_inherit` | Додає поля та кнопки до виробничих замовлень |
| `mrp.qc.template`             | Нова       | Шаблон набору параметрів перевірки      |
| `mrp.qc.template.line`        | Нова       | Рядок шаблону (параметр, норми)         |
| `mrp.qc.inspection`           | Нова       | Акт перевірки / випробувань             |
| `mrp.qc.inspection.line`      | Нова       | Рядок акту (фактичний вимір)            |
| `mrp.product.passport`        | Нова       | Паспорт виробу                          |
| `mrp.passport.component.line` | Нова       | Рядок комплектуючих паспорта            |

### Статусна машина актів перевірки

```
Чернетка → В процесі → Завершено → Затверджено
                                 ↘ Відхилено
                    ← ← ← ← ← (скинути до чернетки)
```

### Статусна машина паспорта виробу

```
Чернетка → Видано
         ↘ Анульовано
```

## Встановлення

### Вимоги

- Odoo **18.0 Community Edition**
- Встановлені модулі: `mrp`, `stock`, `mail`

### Кроки встановлення

1. Скопіюйте папку `addons/manufacturing_passport` до директорії додаткових аддонів вашого Odoo.

2. Оновіть список модулів у Odoo:
   **Налаштування → Технічне → Оновити список модулів**
   або перезапустіть Odoo з параметром `-u base`.

3. Встановіть модуль:
   **Налаштування → Модулі → знайдіть "Manufacturing Passport & QC Inspection" → Встановити**

---

## Налаштування

### 1. Призначте ролі користувачам

Перейдіть до **Налаштування → Користувачі** і призначте відповідні ролі:

| Роль              | Можливості                                                    |
|-------------------|---------------------------------------------------------------|
| **Інспектор ОТК** | Перегляд та заповнення актів перевірки, перегляд паспортів    |
| **Керівник ОТК**  | Усі права інспектора + затвердження актів, видача паспортів, управління шаблонами |

### 2. Налаштуйте шаблони перевірки

Перед початком роботи рекомендується створити шаблони перевірки для кожного типу продукції:

**Виробництво → Контроль якості → Налаштування → Шаблони перевірки**

Для кожного шаблону задайте:
- Прив'язку до продукту або специфікації (BOM)
- Перелік параметрів перевірки з нормами та методами вимірювання

### 3. Переконайтесь, що продукт відстежується за серійним номером

Для видачі паспорта виріб повинен мати серійний номер (`Відстеження: За серійним номером`).

## Робота з модулем

### 1. Шаблони перевірки

**Шлях:** Виробництво → Контроль якості → Налаштування → Шаблони перевірки

Шаблон містить стандартний набір параметрів для певного продукту. При створенні акту перевірки рядки автоматично копіюються з шаблону. Підтримуються два типи параметрів:
- **Кількісний** — задається діапазон (min/max), система автоматично визначає результат при введенні фактичного значення
- **Якісний** — текстовий опис результату

---

### 2. Акт перевірки (випробувань)

#### Створення акту

Відкрийте виробниче замовлення і натисніть кнопку **«Створити акт перевірки»**.

- Якщо для продукту існує активний шаблон — рядки заповнюються автоматично
- Серійний номер підтягується з поля «Серійний номер, що виробляється»

#### Статуси акту

| Кнопка               | Перехід статусу              | Хто може                |
|----------------------|------------------------------|-------------------------|
| Почати перевірку     | Чернетка → В процесі         | Інспектор ОТК           |
| Завершити            | В процесі → Завершено        | Інспектор ОТК           |
| Затвердити           | Завершено → Затверджено      | Керівник ОТК            |
| Відхилити            | Завершено → Відхилено        | Керівник ОТК            |
| Скинути до чернетки  | Будь-який → Чернетка         | Керівник ОТК            |

#### Заповнення результатів

У таблиці рядків введіть фактичне значення для кожного параметра. Для кількісних параметрів результат (`Придатний` / `Непридатний`) визначається автоматично. Загальний результат акту оновлюється автоматично на основі рядків.

#### Друк акту

Натисніть **«Друкувати акт»** — система сформує PDF-документ.

---

### 3. Паспорт виробу

#### Створення паспорта

Відкрийте виробниче замовлення і натисніть кнопку **«Створити паспорт виробу»**.

**Умови для створення паспорта:**
- Є хоча б один **затверджений** акт перевірки для цього замовлення
- Для замовлення ще не видано паспорт

При створенні паспорта автоматично:
- Підтягуються всі списані комплектуючі з фактичними партіями та серіалами
- Заповнюється дата виготовлення (з дати завершення замовлення)
- Розраховується дата закінчення гарантії

#### Видача паспорта

Після перевірки даних натисніть **«Видати паспорт»**. Для видачі обов'язково вказати серійний номер виробу.

#### Друк паспорта

Натисніть **«Друкувати паспорт»** — система сформує PDF-документ з усіма реквізитами.

---

### Загальний бізнес-процес

```
Виробниче замовлення (done)
        │
        ▼
[Створити акт перевірки]
        │
        ▼
Заповнити результати вимірювань
        │
        ▼
Затвердити акт (Керівник ОТК)
        │
        ▼
[Створити паспорт виробу]
        │
        ▼
Видати паспорт → Друк PDF
```

## Технічна інформація

- **Версія Odoo:** 18.0
- **Версія модуля:** 18.0.1.0.0
- **Ліцензія:** LGPL-3
- **Залежності:** `mrp`, `stock`, `mail`
- **Python:** 3.12

### Використані технічні патерни Odoo 18

- `_inherit` — розширення існуючої моделі `mrp.production` без копіювання
- `@api.model_create_multi` — правильний override `create()` для пакетних операцій
- `fields.Command` — сучасний API для запису One2many/Many2many (Odoo 17+)
- `mail.thread` / `mail.activity.mixin` — вбудований чатер та активності
- `ir.sequence` — наскрізна нумерація документів
- `models.Constraint` — SQL-обмеження через новий Odoo 17+ API
- QWeb-звіти (`ir.actions.report`) — друк PDF
- Рольова безпека через `ir.model.access.csv` + групи безпеки
